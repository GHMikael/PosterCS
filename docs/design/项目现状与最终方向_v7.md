### 2.1 Gold 分布 (annotatorA, 60 张, adjudicated)

| class | n | % |
|---|---|---|
| `none` | 35 | 58% |
| `structure_alignment_error` | 14 | 23% |

| `other` | 1 | 2% |
| `text_overload` / `asset_mismatch` / `hierarchy_emphasis_error` | 0 | 0% |

**关键发现:**
- `text_overload`/`asset_mismatch`/`hierarchy_emphasis_error` **全部为 0**——生成优化消除了语义类缺陷
- 残余缺陷全为几何/布局类：`structure_alignment`(storyflow 右侧留白通病), `asset_too_small`(图尺寸代码 bug)
- Per-template: storyflow 14/14 `structure_alignment`, dashboard 最佳

### 2.2 VLM vs Gold

| metric | direct | narrowed | prior baseline |
|---|---|---|---|
| accuracy | 0.083 | 0.167 | 0.583 |
| κ(VLM, gold) | 0.016 | 0.089 | — |
| recall(none) | 0.0 | 0.0 | — |
| recall(asset_too_small) | 0.0 | 0.0 | — |
| FP rate space_imbalance | 0.79 | 0.71 | — |
| top-1 share | 0.77 | 0.70 | — |

### 2.3 Verdict: **S1** (VLM critic 不可靠)

- S2 条件：macro_recall ≥ 0.70 + κ ≥ 0.60 + (acc − prior) ≥ 0.15 → 全部不满足
- S1 条件：acc ≤ prior+0.05 或 κ < 0.20 + top1 ≥ 0.5 → **全部满足**
- S3 条件：同时有 reliable + blind classes → **不满足**（reliable 为空, blind = [asset_too_small, none]）

**判决焊死：整图 VLM critic 在所有指标上均不优于先验猜测。** 这是论文 S1 诊断半边的核心证据。
