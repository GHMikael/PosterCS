# PosterCS 学术海报视觉缺陷 Taxonomy v4.2（正式实验冻结版）

本版继承 v4.1 的九个可见缺陷标签与严重度定义。Round 2 表明
`figure_detail_unreadable` 已稳定，而 `space_imbalance` 与
`overlap_or_clipping` 需要更机械的检查顺序。正式审核时先执行下列检查，
再进行整体判断。

## 强制检查清单

1. **裁断检查**：逐区查看正文、图注、标题、作者和页脚。可见 `...` 且语义未完成，
   或文字/图片被遮挡、越界、删除尾部，记录 `overlap_or_clipping`。
   单纯作者列表过长但已明确使用 “et al.” 不算裁断。
2. **图内可读检查**：只检查理解主要方法或结果所必需的轴、图例、节点、数字和标签。
   在整图适应窗口条件下无法辨认，记录 `figure_detail_unreadable`。
3. **空间检查**：只有“大块无信息留白”和“其他区域明显拥挤或视觉重量偏斜”同时成立，
   才记录 `space_imbalance`。内容较少但不存在拥挤时不记录。
4. **文字负担检查**：文字本身可读，但总量、长段落或 bullet 数使重点无法快速扫描，
   记录 `text_overload`；bullet 样式重复或主观单调不构成缺陷。
5. 再检查正文过小、对齐、层级、资源损坏和无法归类的其他可见缺陷。

## 标签定义

| 标签 | 报告条件 |
|---|---|
| `body_text_too_small` | 实质正文因字号、对比度或行距无法连续阅读 |
| `figure_detail_unreadable` | 理解图表所需的标签、节点、数字或图例无法辨认 |
| `text_overload` | 内容可读但总量妨碍快速扫描重点 |
| `space_imbalance` | 大块无信息留白与局部拥挤并存，或视觉重量明显偏向一侧 |
| `alignment_error` | 网格、列宽、边距、模块边界或基线出现明显非设计性错位 |
| `weak_hierarchy` | 阅读入口、顺序或核心结论不清，次要元素抢占焦点 |
| `overlap_or_clipping` | 有意义的文字或图片被遮挡、越界或裁断，内容实际丢失 |
| `asset_missing_or_broken` | 空框、加载失败、异常残片、错误拉伸/旋转或图片损坏 |
| `other` | 达到 moderate/severe 且无法映射到以上标签的可见缺陷 |

`none` 表示没有达到 moderate/severe 的问题，不能与其他标签同时出现。

## 严重度与 Primary

- 1 minor：稳定可见，但不妨碍主要阅读或理解；只作探索性记录。
- 2 moderate：明显降低阅读效率、理解准确性或专业呈现，应当修复。
- 3 severe：关键内容无法读取、阅读路径被破坏或存在硬渲染故障。

正式主分析只使用严重度 2–3。Primary 必须来自严重度 2–3 的已记录问题。
多个问题并存时依次比较：实际内容丢失或硬故障、严重度、信息重要性、覆盖面积。

## Gold 形成方式

候选标签可以由独立 AI 或确定性规则预填，但候选结果本身不是 Gold。
自然集必须经人工逐张接受或修改；分层子集再由第二位标注者独立盲标，
分歧经仲裁后形成最终 Gold。可控集以注入标签为先验，并由人工确认注入可见且
未引入额外缺陷。待测 VLM 输出不得展示在人工审核页。
