- [x] Journal Track full-paper deadline：2026-11-15（AoE）

- [x] Final decision：2027-05-15

注意：初审若为 Major Revision，稿件将无法继续留在 Journal Track，但可以转入 regular IJDAR review。

## 内容与格式

- [x] 原创研究稿，不是已发表会议论文的期刊扩展
- [x] 主题属于 document analysis and recognition
- [x] 英文结构化摘要包含 Purpose / Methods / Results / Conclusion
- [x] 英文摘要 229 词，位于 150–250 词范围内
- [x] 英文关键词 6 个，位于 4–6 个范围内
- [ ] Springer Nature LaTeX 模板，双栏选项 `iicol`
- [ ] 双栏、含图不超过 20 页；若超页必须在 cover letter 中解释
- [ ] 标题、作者、单位、通讯作者邮箱和 ORCID 完整
- [ ] 50–100 词作者简介和黑白证件照
- [ ] 数字顺序引用，参考文献 DOI 使用完整链接
- [ ] 所有表格和图片按正文出现顺序编号并引用
- [ ] 最终尺寸下图中文字保持 8–12 pt 左右且可辨认
- [ ] 提交 PDF、LaTeX 源文件、BibTeX、图片和必要 style 文件

## 声明与可复现性

- [ ] Data Availability Statement 替换占位符
- [ ] Competing Interests 替换占位符
- [ ] Funding 替换占位符
- [ ] Author Contributions / CRediT 替换占位符
- [ ] Ethics Declaration 由作者确认
- [ ] AI Tool Use Disclosure 按 Springer/IJDAR 政策确认
- [ ] 数据、代码、Prompt、冻结配置和预测结果的发布位置确定
- [ ] 不能公开的论文图像或素材明确版权与访问边界

## 科学质量门

- [x] Formal、RuleDev、Controlled 和 External 的职责与冻结顺序明确
- [x] Primary contrast 与 secondary comparisons 明确
- [x] Hybrid 相对 Source-aware Rule 的非显著结果如实报告
- [x] External-Natural-20 不被包装成 source-aware 系统外部验证
- [x] Repair 仅作为 implementation feasibility
- [x] 最近邻 IJDAR VLM-OCR 工作已纳入定位
- [ ] 全部 23 个参考文献完成 citation-faithfulness 核验
- [ ] IJDAR 定向模拟审稿通过，无 Critical/Major 投稿阻断项

## 投稿前仍需作者本人提供

1. 作者顺序、单位、通讯作者与 ORCID；
2. 基金项目与编号；
3. 利益冲突声明；
4. 数据和代码公开策略；
5. 伦理审查是否适用的最终表述；
6. 作者简介与照片；
7. 参会承诺。
